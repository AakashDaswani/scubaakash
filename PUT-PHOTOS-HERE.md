# Product photos go in this folder

1. Drop the image file in here (jpg or png).
2. Give it a simple name: `samsung-65-tv.jpg` — lowercase, no spaces.
3. In `js/data.js`, add this line to that product:

   image: "images/samsung-65-tv.jpg",

Resize photos to about 1000px wide first — <https://squoosh.app> is free and
does it in the browser. A 5MB phone photo will make the site very slow on
mobile data.

Products with no photo show a coloured tile with the category emoji instead,
so nothing looks broken while you work through them.

(You can delete this file once you've added some photos.)
